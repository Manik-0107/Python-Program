# 🛠 How to Run the Programs

Clone the repository:

```
git clone https://github.com/Manik-0107/Python-Program.git
```

Navigate to the folder:

```
cd Python-Program
```

Run any Python program.

Example:

```
python "49 Recursion/01 Factorial.py"
```

or

```
python3 "49 Recursion/01 Factorial.py"
```
